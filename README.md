# Machine Learning Lab

## Overview

This repository contains my initial hands-on practice with Machine Learning concepts and algorithms during my internship. It represents my learning phase, where I explored fundamental machine learning techniques, implemented basic examples, and gained practical experience working with Python, Jupyter Notebooks, and datasets.

The primary purpose of this repository is to document my learning process and build a foundation for developing more structured, maintainable, and reliable machine learning solutions.

## Purpose of This Repository

This repository focuses on learning and understanding the fundamentals of Machine Learning through practical implementations.

The code included here consists of basic learning exercises and implementations that were developed to understand how different algorithms and techniques work. Although the code runs in its current environment, it has not necessarily undergone comprehensive code review, security review, optimization, or production-readiness improvements.

This repository should therefore be considered a learning and experimentation repository rather than a collection of production-ready solutions.

## Projects and Topics Covered

The repository explores the following Machine Learning concepts and techniques:

1. **Linear Regression** — Understanding simple and multiple linear regression for predicting continuous values.
2. **Gradient Descent** — Learning the fundamentals of optimization and minimizing model error.
3. **Saving Machine Learning Models** — Practicing model serialization and loading trained models for reuse.
4. **One-Hot Encoding** — Converting categorical variables into numerical representations.
5. **Train-Test Split** — Splitting datasets to evaluate model performance on unseen data.
6. **Logistic Regression** — Exploring supervised classification techniques.
7. **Decision Tree** — Understanding tree-based classification and prediction.
8. **Support Vector Machine (SVM)** — Learning classification through decision boundaries and margins.
9. **Random Forest** — Exploring ensemble learning using multiple decision trees.
10. **K-Fold Cross-Validation** — Practicing model evaluation across multiple data splits.
11. **K-Means Clustering** — Understanding unsupervised learning and data clustering.
12. **Naive Bayes** — Exploring probabilistic classification based on Bayes' theorem.
13. **Grid Search** — Learning systematic hyperparameter tuning.
14. **Regularization** — Understanding L1 and L2 techniques for controlling model complexity.
15. **K-Nearest Neighbors (KNN)** — Exploring distance-based classification and regression.
16. **Principal Component Analysis (PCA)** — Learning dimensionality reduction techniques.
